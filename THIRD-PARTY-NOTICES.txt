How this list was produced
------------------------------------------------------------------------------

Nothing here is written from memory or inferred from a package name.

  npm packages   The sidecar bundle is rebuilt with esbuild's metafile enabled,
                 which reports every input file that was inlined. Each input is
                 mapped back to its package, and the licence is read from that
                 package's own package.json. Packages shipped unbundled beside
                 the sidecar are read directly from sidecar/build/node_modules.

  UI packages    `npm ls --omit=dev --all` in app/, which lists the window's
                 production dependencies and everything they depend on. The
                 licence is read from each package's own package.json.

  Rust crates    `cargo metadata --filter-platform x86_64-pc-windows-msvc`, for
                 both app/src-tauri and setup/src-tauri, walking normal
                 dependencies only from the workspace root. Build-dependencies
                 and dev-dependencies are excluded: neither is linked into a
                 shipped binary. Licence identifiers are the `license` field of
                 each crate's own Cargo.toml.

  Licence texts  Quoted from a real licence file on disk, with the file that was
                 quoted named at the top of each text.

A package whose licence could not be established from its own metadata would be
listed here as undetermined. At the time of writing there are none.

10. The Linux build
==============================================================================

The Linux app is a Flatpak that runs on the GNOME runtime from Flathub. It
carries the same application and the same third-party software as the Windows
build, listed in sections 1 to 7 and 9, except for what this section names.
The GNOME runtime and the codecs extension it brings are installed by Flatpak
from Flathub and are not part of this bundle. Inside the Flatpak this file,
LICENSE and NODE-LICENSE.txt are in /app/share/licenses/eu.akoos.photos.

------------------------------------------------------------------------------
Node.js runtime
------------------------------------------------------------------------------

The sidecar runs on Node.js v24.22.3 for Linux x64, built by the Flatpak SDK's
Node.js 24 extension (org.freedesktop.Sdk.Extension.node24) from the official
source release, and installed as /app/bin/resources/sidecar-runtime. This
application modifies no Node.js source or code. Node.js is licensed MIT, and
the licence and notices it carries are installed as NODE-LICENSE.txt, taken
from that extension.

  Node.js v24.22.3
  https://nodejs.org/
  Licence: MIT

libvips and its dependencies under LGPL-3.0-or-later; the licence file

ffmpeg
------------------------------------------------------------------------------

The Linux app compresses videos with its own build of ffmpeg, installed as
/app/bin/resources/ffmpeg/ffmpeg and ffprobe. It is built by ffmpeg/build.sh in
